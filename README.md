## 🎯 워크샵 목표

```mermaid
graph LR
    A[호텔 업무 고민] -->|Kiro에 설명| B[AI가 코드 생성]
    B -->|바로 실행| C[업무 자동화 완성!]
```

| 목표          | 설명                   |
| ----------- | -------------------- |
| 🧠 AI 도구 이해 | Kiro IDE가 무엇인지 알기    |
| ✍️ 직접 만들기   | 호텔 업무에 쓸 수 있는 도구 만들기 |
| 💪 자신감 얻기   | "나도 할 수 있다!" 경험하기    |
