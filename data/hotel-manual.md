# 🏨 롯데호텔 서비스 매뉴얼 (샘플 데이터)

> 이 문서는 워크샵 실습용 샘플 데이터입니다.

---

## 1. 체크인 절차

### 1.1 일반 체크인
1. 고객 도착 시 밝은 미소로 인사: "안녕하세요, 롯데호텔에 오신 것을 환영합니다."
2. 예약 확인: 고객 성함 또는 예약번호로 PMS 시스템 조회
3. 신분증 확인: 여권 또는 주민등록증 (외국인은 여권 필수)
4. 등록카드 작성 요청
5. 객실 키 발급 및 안내
6. 조식 포함 여부, 체크아웃 시간 안내
7. 벨맨 호출하여 짐 운반 지원

### 1.2 얼리 체크인
- 14:00 이전 체크인 요청 시
- 객실 준비 상태 확인 후 가능 여부 안내
- 불가 시: 짐 보관 서비스 안내, 로비 라운지 이용 권유
- 추가 요금: 06:00~10:00 도착 시 전일 요금의 50%, 10:00~14:00 도착 시 무료 (객실 상황에 따라)

### 1.3 VIP 체크인
- VIP 등급: VVIP, VIP, MVP
- VVIP: 로비 대기 없이 객실 직접 안내, 웰컴 어메니티 세팅 완료 상태
- VIP: 우선 체크인 카운터 이용, 웰컴 드링크 제공
- MVP: 일반 카운터 이용, 포인트 적립 안내

## 2. 체크아웃 절차

### 2.1 일반 체크아웃
1. 체크아웃 시간: 12:00 (정오)
2. 미니바 사용 내역 확인
3. 추가 요금 정산 (룸서비스, 부대시설 등)
4. 결제 처리
5. 영수증 발급
6. "감사합니다. 다음에 또 뵙겠습니다." 인사

### 2.2 레이트 체크아웃
- 12:00~14:00: 무료 (객실 상황에 따라)
- 14:00~18:00: 정상 요금의 50%
- 18:00 이후: 1박 추가 요금

## 3. 객실 업그레이드 정책

### 3.1 무료 업그레이드 기준
- 리워드 회원 상위 등급 (VIP 이상)
- 예약 객실 타입 만실 시
- 허니문/기념일 고객 (사전 요청 시)
- 컴플레인 보상 차원

### 3.2 유료 업그레이드
- 체크인 시 상위 객실 제안 (Upselling)
- 업그레이드 요금표에 따라 차액 결제
- 디럭스 → 프리미어: +50,000원
- 프리미어 → 스위트: +150,000원

### 3.3 업그레이드 불가 상황
- 성수기 만실 시
- 그룹 예약으로 객실 블록 시
- 이미 최상위 객실 예약 시

## 4. 컴플레인 대응 매뉴얼

### 4.1 기본 원칙 (LEARN)
- **L**isten: 경청하기
- **E**mpathize: 공감하기
- **A**pologize: 사과하기
- **R**esolve: 해결하기
- **N**otify: 보고하기

### 4.2 상황별 대응

#### 객실 청소 불만
- 즉시 하우스키핑 재청소 요청
- 대기 시간 동안 로비 라운지 음료 제공
- 심각한 경우: 객실 변경 + 어메니티 제공

#### 소음 불만
- 소음 원인 파악
- 가능 시 객실 이동
- 불가 시: 귀마개 제공 + 다음 방문 할인 쿠폰

#### 시설 고장
- 엔지니어링팀 즉시 호출
- 수리 불가 시 객실 변경
- 불편 보상: 미니바 무료 또는 조식 제공

### 4.3 보상 권한 (직급별)
| 직급 | 보상 범위 |
|------|-----------|
| 프론트 스태프 | 음료/어메니티 제공 (5만원 이하) |
| 듀티 매니저 | 객실 업그레이드, 식음 크레딧 (20만원 이하) |
| 프론트 매니저 | 1박 무료, 대규모 보상 (50만원 이하) |
| 총지배인 | 제한 없음 |
