# Steering 작성하기

## 🎯 목표

직접 Steering 파일을 만들어서 AI를 **롯데호텔 업무 도우미**로 만들어봅시다!

***

## Step 1: Steering 파일 생성 📝

Kiro IDE의 AI 채팅창에 다음과 같이 입력하세요:

```
프로젝트에 steering 파일을 만들어줘.
롯데호텔 프론트 데스크 업무를 도와주는 AI 도우미 역할이야.
```

> 💡 Kiro가 자동으로 `.kiro/steering/` 폴더와 파일을 만들어줍니다!

***

## Step 2: Steering 내용 확인 👀

생성된 파일을 열어보면 이런 내용이 있을 거예요:

```markdown
# 롯데호텔 프론트 데스크 도우미

## 역할
- 롯데호텔 프론트 데스크 업무를 지원하는 AI 도우미입니다.

## 규칙
- 항상 한국어로 답변합니다.
- 친절하고 전문적인 톤을 유지합니다.
- 롯데호텔 서비스 매뉴얼을 기반으로 답변합니다.

## 참고 자료
- 서비스 매뉴얼 (체크인/체크아웃 절차)
- 객실 업그레이드 정책
- 컴플레인 대응 매뉴얼
```

***

## Step 3: 내용 보강하기 💪

AI 채팅창에서 Steering을 더 구체적으로 만들어봅시다:

```
steering 파일에 다음 내용을 추가해줘:
- 체크인 시간은 15:00, 체크아웃 시간은 12:00
- VIP 고객 문의는 항상 "매니저에게 확인 후 안내드리겠습니다" 라고 답변
- 답변 형식은 항상 번호 목록으로
- data/hotel-manual.md 파일을 참고 자료로 사용
- 코드 생성 시 npm, node.js 등 외부 패키지를 사용하지 않는다
- 순수 HTML, CSS, JavaScript만 사용한다
- 결과물은 .html 파일 하나로 완성한다
```

***

## Step 4: 테스트해보기 🧪

Steering이 잘 적용되었는지 확인해봅시다!

AI 채팅창에 질문해보세요:

```
체크인 절차를 알려줘
```

### ✅ 잘 된 경우

* 롯데호텔 매뉴얼 기반으로 답변
* 번호 목록 형식으로 답변
* 친절한 톤

### ❌ 안 된 경우

* 일반적인 호텔 정보로 답변
* Steering 파일이 제대로 저장되었는지 확인

## 🔧 트러블슈팅

### "Steering이 적용 안 되는 것 같아요"

* `.kiro/steering/` 폴더 안에 파일이 있는지 확인
* 파일 확장자가 `.md`인지 확인
* Kiro를 재시작해보세요

### "AI가 엉뚱한 답변을 해요"

* Steering에 더 구체적인 규칙 추가
* "반드시", "항상" 같은 강조 표현 사용
* 예시를 포함시켜보세요
