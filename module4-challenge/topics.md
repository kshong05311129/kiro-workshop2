# 실습 주제 선택

## 주제 1: 서비스 매뉴얼 검색 도우미 🔍

> **난이도**: ⭐⭐ | **추천 방식**: Spec 기반

### 설명

수백 페이지의 서비스 매뉴얼에서 원하는 내용을 빠르게 찾아주는 도구

### 프롬프트 예시

```
호텔 서비스 매뉴얼 검색 도우미를 만들어줘.

- 검색어를 입력하면 관련 매뉴얼 내용을 보여줌
- 카테고리: 체크인, 체크아웃, 컴플레인, 객실, 부대시설
- 검색 결과를 카드 형태로 표시
- 롯데호텔 색상 (네이비 #1B2B4B, 골드 #C5A572)
- data/hotel-manual.md 파일 내용을 데이터로 사용
```

### 완성 기준

* [ ] 검색어 입력 시 관련 내용 표시
* [ ] 카테고리 필터 동작
* [ ] 깔끔한 UI

## 주제 2: 고객 컴플레인 대응 보고서 생성기 😤

> **난이도**: ⭐⭐ | **추천 방식**: Vibe Coding

### 설명

컴플레인 상황을 입력하면 대응 보고서가 자동으로 생성되는 도구

### 프롬프트 예시

```
고객 컴플레인 대응 보고서 생성기를 만들어줘.

입력 항목:
- 고객명, 객실번호, 날짜
- 컴플레인 유형 (객실 청소, 소음, 시설 고장, 서비스 불만, 기타)
- 상황 설명 (텍스트 입력)
- 대응 조치 (선택형 + 텍스트)
- 보상 내역

출력:
- 정형화된 보고서 형식으로 생성
- 인쇄 가능한 레이아웃
- 복사 버튼
```

### 완성 기준

* [ ] 모든 입력 항목이 있음
* [ ] 보고서가 깔끔하게 생성됨
* [ ] 인쇄/복사 가능

## 주제 3: 예약 확인 메일 생성기 📧

> **난이도**: ⭐ | **추천 방식**: Vibe Coding

### 설명

고객 정보를 입력하면 예약 확인 메일이 자동으로 완성되는 도구

### 프롬프트 예시

```
예약 확인 메일 생성기를 만들어줘.

입력:
- 고객명 (한글/영문)
- 체크인 날짜, 체크아웃 날짜
- 객실 타입 (디럭스, 프리미어, 스위트)
- 조식 포함 여부
- 특별 요청사항

출력:
- 한국어 메일 버전
- 영어 메일 버전
- 복사 버튼
- 롯데호텔 스타일 (정중하고 격식있는 톤)
```

### 완성 기준

* [ ] 입력 폼이 있음
* [ ] 한국어/영어 메일 생성
* [ ] 복사 기능 동작

## 주제 4: 객실 점검 체크리스트 🛏️

> **난이도**: ⭐ | **추천 방식**: Vibe Coding

### 설명

객실 점검 시 사용할 수 있는 디지털 체크리스트

### 프롬프트 예시

```
객실 점검 체크리스트 웹앱을 만들어줘.

기능:
- 객실 번호 입력
- 점검 항목 체크 (침구, 욕실, 어메니티, 미니바, 전자기기, 청결도)
- 각 항목에 메모 추가 가능
- 점검 완료 시 요약 보고서 생성
- 문제 있는 항목은 빨간색으로 표시
- 점검 날짜/시간 자동 기록
```

### 완성 기준

* [ ] 체크리스트 항목이 있음
* [ ] 체크/언체크 가능
* [ ] 요약 보고서 생성

## 주제 5: VIP 고객 맞춤 안내 생성기 👑

> **난이도**: ⭐⭐⭐ | **추천 방식**: Spec 기반

### 설명

VIP 등급에 따라 맞춤형 안내문을 자동 생성하는 도구

### 프롬프트 예시

```
VIP 고객 맞춤 안내 생성기를 만들어줘.

입력:
- 고객명
- VIP 등급 (VVIP, VIP, MVP)
- 방문 목적 (비즈니스, 레저, 기념일, 허니문)
- 체크인 날짜

출력 (등급별 차별화):
- 환영 인사 (등급별 다른 톤)
- 이용 가능 혜택 안내
- 추천 서비스 (방문 목적에 맞게)
- 전담 컨시어지 연락처

디자인:
- 고급스러운 느낌
- 등급별 다른 색상 (VVIP: 골드, VIP: 실버, MVP: 브론즈)
```

### 완성 기준

* [ ] 등급별 다른 안내문 생성
* [ ] 방문 목적에 맞는 추천
* [ ] 고급스러운 디자인
