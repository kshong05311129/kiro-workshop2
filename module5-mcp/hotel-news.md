# 🏨 실습: 호텔 업계 동향 리서치

## 🎯 목표

웹서치 MCP를 활용해서 **호텔 업계 최신 동향을 AI가 검색하고 정리**하도록 해봅시다!

---

## 실습 1: 호텔 업계 트렌드 리서치 📰

### AI에게 요청하기

채팅창에 다음과 같이 입력하세요:

```
2025년 호텔 업계 최신 트렌드를 웹에서 검색해서 정리해줘.

다음 형식으로 정리해줘:
- 트렌드 제목
- 간단한 설명 (2-3줄)
- 우리 호텔에 적용할 수 있는 아이디어

5개 정도로 정리해줘.
```

### 기대 결과

AI가 실시간으로 웹을 검색해서 최신 호텔 트렌드를 정리해줍니다!

> 💡 MCP 연결 전에는 "학습된 정보"만 답변했지만, 이제는 **실시간 검색 결과**를 기반으로 답변합니다.

---

## 실습 2: 경쟁사 동향 파악 🔍

```
국내 5성급 호텔들의 최근 새로운 서비스나 프로모션을 검색해서 정리해줘.

표 형식으로:
| 호텔명 | 새로운 서비스/프로모션 | 시작일 | 특징 |
```

---

## 실습 3: 고객 트렌드 분석 📊

```
2025년 호텔 고객들이 가장 중요하게 생각하는 것들을 검색해서 알려줘.

- MZ세대 고객 선호 트렌드
- 해외 관광객 트렌드
- 비즈니스 고객 트렌드

각각 3가지씩 정리하고, 우리 호텔에서 바로 적용할 수 있는 아이디어도 제안해줘.
```

---

## 실습 4: 보고서 형태로 만들기 📋

위 실습 결과가 마음에 들면, 한 단계 더 나아가봅시다:

```
위에서 검색한 호텔 업계 동향을 바탕으로
팀 회의에서 발표할 수 있는 1페이지 보고서를 HTML로 만들어줘.

- 제목: "2025년 호텔 업계 동향 브리핑"
- 깔끔한 디자인
- 핵심 트렌드 3가지
- 우리 호텔 적용 제안
- 인쇄하기 좋은 A4 레이아웃
```

생성된 HTML 파일을 파일 탐색기(Windows) 또는 Finder(Mac)에서 **더블클릭**하면 브라우저에서 확인할 수 있습니다!
