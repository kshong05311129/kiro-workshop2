# 🔌 MCP 활용 실습

## 🎯 목표

MCP 연결 전후의 차이를 직접 체험해봅시다!

---

## 실습 1: MCP 없이 질문하기 ❌

먼저 MCP를 **비활성화**한 상태에서 질문해봅시다.

> 💡 MCP 설정 파일에서 `"disabled": true`로 바꾸고 저장하면 비활성화됩니다.

채팅창에 입력:

```
AWS Lambda의 최대 실행 시간 제한은 몇 분이야?
```

AI가 답변하지만, **학습된 정보에 의존**하기 때문에 부정확하거나 오래된 정보일 수 있습니다.

---

## 실습 2: MCP 연결 후 같은 질문하기 ✅

이제 MCP를 다시 **활성화**합니다.

> 💡 MCP 설정 파일에서 `"disabled": false`로 바꾸고 저장하세요.

같은 질문을 다시 해봅시다:

```
AWS Lambda의 최대 실행 시간 제한은 몇 분이야? AWS 공식 문서에서 찾아줘.
```

이번에는 AI가 **AWS 공식 문서를 직접 검색**해서 정확한 답변을 제공합니다!

---

## 실습 3: 다양한 질문 해보기 🧪

MCP가 연결된 상태에서 자유롭게 질문해보세요:

```
AWS에서 제공하는 데이터베이스 서비스 종류를 공식 문서에서 찾아서 정리해줘
```

```
S3 버킷 생성 방법을 공식 문서 기반으로 단계별로 알려줘
```

```
AWS 프리 티어에서 무료로 쓸 수 있는 서비스 목록을 찾아줘
```

---

## 💡 핵심 포인트

| | MCP 없음 | MCP 있음 |
|---|---|---|
| 정보 출처 | AI가 학습한 과거 데이터 | **공식 문서 실시간 검색** |
| 정확도 | 오래되었거나 부정확할 수 있음 | 공식 문서 기반으로 정확 |
| 신뢰도 | 출처 불명확 | 문서 URL 제공 가능 |

> 🎉 **이것이 MCP의 핵심입니다!**
> AI에게 외부 도구(이 경우 AWS 문서 검색)를 연결하면, 더 정확하고 신뢰할 수 있는 답변을 받을 수 있습니다.

---

## 🌍 MCP로 연결할 수 있는 것들

오늘은 AWS 문서를 연결했지만, MCP로 다양한 외부 도구를 연결할 수 있습니다:

| MCP 서버 | 기능 |
|----------|------|
| AWS Docs | AWS 공식 문서 검색 |
| GitHub | 코드 저장소 접근 |
| Slack | 메시지 전송 |
| Google Drive | 문서 읽기/쓰기 |
| Database | DB 조회 |

> 💡 MCP는 계속 발전하고 있어서, 앞으로 더 많은 도구를 AI에 연결할 수 있게 됩니다!
